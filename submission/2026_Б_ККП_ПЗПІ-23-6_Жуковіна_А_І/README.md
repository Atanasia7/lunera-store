## Перед публікацією

- переконатися, що `.env` та інші секрети не відстежуються Git;
- виконати `npm run lint` і `npm run build`;
- перевірити запуск проєкту за інструкцією з кореневого `README.md`;
- перевірити відео, презентацію та документи після завантаження.
